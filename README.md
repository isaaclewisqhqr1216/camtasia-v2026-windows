## Overview

Camtasia is a Windows PC application that combines screen capture with video editing. Recording and post-production take place within the same workflow, allowing footage to move from capture to a completed video without requiring several separate applications.

This repository focuses on a desktop release that supports LUT handling and export presets. Together, these options provide additional control over the appearance of recordings and the way finished videos are prepared for different output requirements.
